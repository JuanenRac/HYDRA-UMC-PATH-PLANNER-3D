If you found a real error in the RRT* implementation or collision engine, please open a **GitHub Issue** in this repository. 
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- We do not provide support for non-robotic path planning (e.g., standard game AI).
- Please do not use Issues for "How to" questions.
